## 绝对收敛和条件收敛

### 定义

如果 ∑an 和 ∑∣an∣都收敛**，则称 ∑an **绝对收敛。

如果 ∑an **收敛**，但 ∑∣an∣发散**，则称 ∑an **条件收敛。

### **<u>绝对收敛判别法</u>**

如果 ∑∣an∣ 收敛，那么 ∑an 一定收敛。



> ## 一句话口诀
>
> > **加绝对值收敛 → 绝对收敛（原级数一定收敛）**
> > **原级数收敛，但加绝对值发散 → 条件收敛**

## 重排定理

所谓级数 ∑an的**重排**，是指仅仅改变项的顺序而得到的新级数。例如：

a1+a2+a5+a4+a3+a20+a6+a7+a15+…





若 ∑an 是**绝对收敛**的级数，和为 S，则它的**任意重排**都收敛到**同一个和** S。

若 ∑an 是**条件收敛**的级数，且 r 是任意实数，则存在一种重排，使得新级数的和等于 r。



这个定理非常反直觉！它告诉我们：

- **绝对收敛**的级数很“稳定”，随便怎么打乱顺序，和都一样。
- **条件收敛**的级数很“脆弱”，顺序一变，和可以变成任何你想要的数（比如 100、-5、π……）。











# **<u>级数判别法的策略总结</u>**

![77848937596](assets/1778489375962.png)





第1步：看通项是否趋于0？
       │
       ├─ 否 → 发散（发散检验）→ 结束
       │
       └─ 是 ↓

第2步：识别类型
       │
       ├─ p-级数 1/n^p → 直接判断（p>1收敛）
       │
       ├─ 几何级数 ar^(n-1) → 直接判断（|r|<1收敛）
       │
       ├─ 交错级数 (-1)^(n-1) b_n → 交错级数判别法
       │
       └─ 其他 ↓

第3步：选择判别法
       │
       ├─ 有阶乘/指数/乘积 → 比值判别法
       │
       ├─ 有 (某式)^n 形式 → 根值判别法
       │
       ├─ 形式类似已知级数 → 比较判别法（普通/极限）
       │
       └─ 能算积分 → 积分判别法









### 常见错误提醒

> ⚠️ **不要一上来就用比值/根值判别法**——先看一眼通项是否趋于 0，如果不趋于 0，直接写发散，省时间。
>
> ⚠️ **比值/根值判别法在 L=1L=1 时无效**，此时需要换其他方法（如比较判别法、积分判别法）。
>
> ⚠️ **交错级数判别法只能判断收敛，不能判断绝对收敛**——要判断绝对收敛，需要单独看绝对值级数。
